# Vite + React + shadcn/ui (TypeScript)

React app with Vite, TypeScript, and shadcn/ui.

## Setup

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` – start dev server
- `npm run build` – production build
- `npm run preview` – preview production build
- `npm run test` – run tests

## Tech

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deploy

Build the app (`npm run build`) and deploy the `dist` folder to any static host (Vercel, Netlify, etc.).
